# Proyecto Evidencia AA3_EV01

## Justificación del Framework
Para este proyecto se seleccionó **Node.js con Express.js**. 

**Justificación:** Express es un framework minimalista y flexible para Node.js que permite estructurar la aplicación bajo el patrón arquitectónico MVC (Modelo-Vista-Controlador). Ofrece un manejo eficiente de rutas, fácil integración con bases de datos y excelente rendimiento para el desarrollo de APIs REST web.
